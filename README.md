# Камень, ножницы, бумага

Учебный проект на vanilla js + html + css: браузерная версия игры "камень,
ножницы, бумага". Игрок выбирает вариант с помощью карточек с иконками,
а интерфейс отображает текущий раунд, счёт игрока и счёт компьютера.

## Структура проекта

- `index.html` — разметка интерфейса;
- `script.js` — логика выбора карточки и состояние интерфейса;
- `circle.js` — анимация кругового эффекта при наведении и выборе;
- `tooltip.js` — всплывающие подсказки;
- `src/style/` — стили проекта;
- `public/` — шрифты и изображения;
- `TASK.md` — исходное задание.

## Требования

Для запуска нужен Python 3. Дополнительные пакеты и сборщик устанавливать не
требуется.

## Запуск

1. Откройте терминал в корне проекта.
2. Запустите локальный сервер:

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

3. Откройте в браузере [http://127.0.0.1:8000](http://127.0.0.1:8000).

Для остановки сервера нажмите `Ctrl+C` в терминале.
